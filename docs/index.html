Esquema 1: Arquitectura Hexagonal Pura (Puertos y Adaptadores)
Documentacion 
flowchart TD
    subgraph Canales_Inbound ["Adaptadores Inbound"]
        WIn["WhatsApp Inbound (Baileys Socket)"] --> Bridge["WhatsApp Tenant Bridge"]
        APIIn["REST API Inbound (Express)"] --> MsgIn["InboundMessage Normalizado"]
        Bridge --> MsgIn
    end

    subgraph Core_Puro ["Dominio Puro D.A.V.I.S. (Sin dependencias externas)"]
        MsgIn --> Router["Intent Router & Scoping Especialistas"]
        Router --> ReAct["Motor ReAct (Think-Act-Observe-Decide)"]
        ReAct --> LLMPort["Puerto: LLMProviderPort"]
        ReAct --> MemoryPort["Puerto: MemoryRepositoryPort"]
        ReAct --> UserPort["Puerto: UserRepositoryPort"]
    end

    subgraph Adaptadores_Outbound ["Adaptadores Outbound"]
        LLMPort --> LLMImpl["llmService (Groq / Ollama / OpenAI)"]
        MemoryPort --> SQLiteMem["sqliteMemoryRepository (Modo WAL)"]
        UserPort --> SQLiteUser["sqliteTenantRepository"]
        ReAct --> OutChan["Puerto: MessageChannelPort"]
        OutChan --> WOut["whatsappChannelAdapter (Entrega WhatsApp)"]
        OutChan --> APIOut["apiChannelAdapter (Respuesta REST)"]
    end

Aislamiento de dominio: El motor de razonamiento desconoce por completo la libreria de mensajeria o el motor de base de datos especifico.

Esquema 4: ERS - Arquitectura Asincrona, Inferencia Especulativa y MCP
Documentacion ERS 
flowchart TD
    Inbound["Canal WhatsApp / REST"] --> Outbox["Transactional Outbox (SQLite: 2ms)"]
    Outbox --> RedisQ["Cola de Eventos Duraderos (Redis / BullMQ)"]
    
    subgraph Worker_Pool ["Pool de Workers Desacoplados"]
        RedisQ --> SpecRouter{"Enrutador Especulativo"}

        LocalSLM --> Checkpoint["Puntos de Control de Estado"]
        CloudLLM --> Checkpoint
        
        Checkpoint --> MCPClient["Cliente MCP (Model Context Protocol)"]
        MCPClient --> ExtTools["Servidores MCP Aislados (Stripe, GitHub, Jira)"]
    end
    
    ExtTools --> OutNotice["Notificacion Asincrona Entregada a David"]

Proximo gran salto: Ejecucion duradera resiliente a reinicios, ahorro del 80% en costes de API y herramientas abiertas MCP.
