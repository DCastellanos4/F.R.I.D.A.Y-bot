# Prepared diagnostic source archive

This isolated source captures execution-stage and projection-failure enums.
It is not the current observation schema 2 reader and must not be used as a
production adapter or as a fallback. Current prepared reader is ers_recovery.

Only generic source and synthetic projection tests are stored here. Runtime
bundles, driver identity bindings, observed metadata and process results are not
part of this public archive. No automatic retries or PM2 mutations are provided.
